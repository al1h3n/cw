| Path / Item                                       | What it is                                                                                                                                                                                                                                  | Required?                                                        |
| ------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------- |
| `Cargo.toml`, `Cargo.lock`                        | Workspace manifest + lockfile — **required to build**                                                                                                                                                                                       | **Required**                                                     |
| `rust-toolchain.toml`, `clippy.toml`, `deny.toml` | Toolchain pin + lint/dependency configuration                                                                                                                                                                                               | **Required**                                                     |
| `crates/`                                         | **All source code** — Rust crates (`proto`, `net`, `media`, `platform`, `agent`, `console`, `viewer`) plus the Svelte/Tauri UI under `crates/console/ui/` (`src/`, `package.json`, `package-lock.json`, `tauri.conf.json`, `capabilities/`) | **Required**                                                     |
| `fuzz/`                                           | Fuzz targets (source)                                                                                                                                                                                                                       | **Required**                                                     |
| `docs/`                                           | Documentation                                                                                                                                                                                                                               | **Required**                                                     |
| `AGENTS.md`                                       | Agent/project instructions                                                                                                                                                                                                                  | **Required**                                                     |
| `ClassWatcher.md`                                 | Project documentation                                                                                                                                                                                                                       | **Required**                                                     |
| `README.md`                                       | Project documentation                                                                                                                                                                                                                       | **Required**                                                     |
| `CONTRIBUTING.md`                                 | Contribution/development instructions                                                                                                                                                                                                       | **Required**                                                     |
| `CLAUDE.md`                                       | Claude/AI project instructions                                                                                                                                                                                                              | **Required**                                                     |
| `LICENSE`                                         | License                                                                                                                                                                                                                                     | **Required**                                                     |
| `spikes/`                                         | Throwaway Phase-0 experiments; context only, never built into the product                                                                                                                                                                   | **Optional**                                                     |
| `.git/`                                           | Git history and repository metadata                                                                                                                                                                                                         | **Optional** — skip if you don't want to share history (~4.6 MB) |
| `dist/`                                           | Compiled `.exe` deliverables                                                                                                                                                                                                                | **Do NOT send**                                                  |
| `target/`                                         | Rust build artifacts; regenerated during build                                                                                                                                                                                              | **Do NOT send**                                                  |
| `node_modules/`                                   | Node.js dependencies; regenerated during build                                                                                                                                                                                              | **Do NOT send**                                                  |
